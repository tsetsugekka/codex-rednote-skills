# 中文发布副本与源文件保护

向 RED Skill、腾讯 SkillHub 或 AI Hub 发布／更新内容前读取；语言适配只发生在发布副本中。

1. 在临时目录按公开清单复制本次指定源版本。源可以是本地安装版、项目维护版或 GitHub 版本；不为发布翻译改动这些原件的 README、SKILL.md 或其他文件。原本已是中文的内容可直接复用，无需重复翻译。用户明确要求改造源 Skill 本身时，才修改该任务涉及的源文件。
2. 将英文、日文的自然语言说明完整译为中文：README、SKILL.md、平台名称文案、简介、介绍、更新说明，以及随包 references 和工作流文档。AI Hub 专用发布说明也用中文；调用其它平台 Skill 时，用户指定的中文要求优先于其默认日文／英文规则。名称优先保留既有中文展示名。
3. 保留全部触发条件、输入输出、权限、安全边界、限制、失败处理、步骤和例子，不用摘要替代翻译。代码、API 字段、命令、标识符、路径、URL 和产品专名保持原意；不为翻译改变脚本行为。源 Skill 的 name、平台 slug、已有 ID 和资源引用关系保持不变。
4. 核对正文资源链接均可解析，引用文档已同步翻译，技术参数与原文一致。技术术语可附原文，发布主体不能停留在英文／日文。根据平台字段限制缩短展示名和简介；主说明超限时保留必要入口，将细节移入随包 Reference，不删除执行契约。
5. AI Hub 若采用 GitHub 来源登记，平台取得的仍是 GitHub 原件，不能宣称已上传中文包。需要中文 README／SKILL.md 的实际包时，使用平台支持的本地上传方式；不为此修改 GitHub 源。账号、条目与审核流程按当前 AI Hub 官方 Skill 执行，用户的中文要求适用于发布副本及平台说明。
6. 记录源提交、翻译范围和包摘要。按目标平台运行预检，检查实际 payload 的名称、简介、正文及包内 README／SKILL.md；不能只翻译展示字段。回读结果，分别登记上传、审核与公开状态。
7. 结果核实并保存不含敏感信息的回执后，清理仅为发布生成的中文副本、AI Hub 专用临时文档、ZIP 和取得的校验副本；失败／中止也清理。本地安装版、GitHub 源、用户已有中文文件及明确要求保留的资料不删。审核仍在进行时可保留条目 ID、版本、源提交和摘要继续核验，无需长期保留临时译文。

用户明确指定其它语言时记录本次例外；无法完整翻译时报告剩余内容，不默认上传英文包。发布语言与原件语言独立，不能从临时副本反向覆盖源。
