# 中文发布副本

在向 RED Skill 或腾讯 SkillHub 打包前读取；这是两个平台共用的语言规则。

1. 在临时目录复制本次源版本的公开文件。源 Skill 的 `name`、平台 `slug`、已有 ID、脚本路径和引用关系保持不变。
2. 将英文、日文的自然语言说明译为中文：平台名称文案、简介、介绍、更新说明、`SKILL.md` 正文，以及随包的 README、references 和工作流文档。已有中文内容只同步本次变化。名称优先保留既有中文展示名。
3. 保留所有触发条件、输入输出、权限、安全边界、限制、失败处理、步骤和例子；不得用摘要替代完整翻译。保留代码、API 字段、命令、标识符、路径、URL 和产品专名；不为翻译改变脚本行为。
4. 核对正文中的资源链接均可解析，引用文档已同步翻译，技术参数与原文一致。技术术语可附原文，发布主体不能停留在英文／日文。
5. 根据平台字段限制缩短展示名和简介；主说明超限时保留必要入口，将条件细节移入随包 Reference，不删除执行契约。
6. 记录源提交和翻译范围。分别运行平台预检，检查实际 payload 的名称、简介、正文，而不只检查副本文件。

仅在用户明确要求其它语言或允许本次英文版本时采用例外并记录；无法完整翻译时先报告剩余内容，不把英文包作为默认中文发布结果。GitHub 源语言与平台发布语言分别维护，除非用户要求修改源。
