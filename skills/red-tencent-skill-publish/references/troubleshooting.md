# RED Skill 故障处理

## 登录过期或工具陈旧

`NEED_LOGIN`、`fetch failed`、令牌过期和续期失败按 [CLI 与授权恢复](red-cli-auth.md) 处理。浏览器登录状态不能代替 CLI 授权，也不因此转成网页提交。

## 展示名被截断或长度被拒绝

曾观察到带空格名称只保留首词。保留原条目身份，将展示名改为无空格且不超过 15 字；重新检查实际 payload 的完整 name，不只相信命令参数。其它字段按 [字段限制](field-limits.md) 处理。

## 上传包包含不支持文件

按 [包规则](package-rules.md) 重建公开中文副本，检查官方工具的实际文件清单。不要通过放宽敏感文件扫描来提交。

## `Skill ID 已被占用`

可能是用普通新建命令更新已有条目、条目仍在审核，或 identifier 属于另一个条目。先核对所有者、原数字 `skill_id`、identifier 和审核状态。

合法已有更新按 [RED 更新流程](red-workflow.md) 使用原身份，并检查 payload 包含数字 ID；不改新 ID 绕过冲突。若必须撤回审核版本，先获得对应授权或等待审核完成。确为不同产品时才由用户决定新建。

## 页面中文、包内仍是英文或日文

按 [中文发布副本](publishing-language.md) 翻译包内主说明和 references。CLI 的 description／detail 编辑可能只改变提交字段，不改 bundle；必须重新制作副本才能同步包内内容。

## 提交超时、拒绝或结果不明确

保存非敏感错误与端点范围。超时先查原条目版本历史，确认是否已提交再决定重做。网络失败或限流遵守当前环境的有界重试规则。新回执只证明提交时，报告 submitted／待审核及 ID，不能宣称审核通过。
