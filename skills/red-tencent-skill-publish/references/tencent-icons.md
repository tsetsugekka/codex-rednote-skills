# 腾讯 SkillHub 图标风格与网页更新

需要设计、重绘或更换腾讯平台图标时读取；普通内容更新不生成图标。本规范沉淀已确认的图标方向，后续用户明确指定新风格时采用新决定。

## 视觉方向

- 采用浅底、现代扁平／编辑图形。暖白、米白、浅纸色或柔和灰蓝底，清晰深蓝轮廓，少量柔和强调色，充分留白。避免黑底科技风、霓虹、发光、密集网格，以及 Vista／Win7 式玻璃、金属高光、镜面渐变、拟物 3D、浮雕、叠层阴影和立体按钮感。
- 一个主符号，最多一个辅助符号；方形构图，主体居中，缩小到 64px 仍一眼可认。不堆叠报纸、放大镜、多张图表等元素，不放文字、字母、数字、水印或冒用品牌标志。
- 系列内统一，系列间可以不同：Sakura 相关用米白、深蓝和樱花粉的简洁运维符号；股票／市场系列用浅底、深蓝线稿和砖红、青绿、赭黄少量点缀的现代财经图形。其它 Skill 可按功能选择独立风格，同时遵守简洁和小尺寸识别原则。
- 用主轮廓和功能语义区分相近 Skill。两个图标太像时改其中一个，不能只换颜色而保留同一主体。浏览器刷新与网页减负等相邻功能应采用不同符号。

## 设计与检查

1. 先查看同系列已确认图标作为参考，读目标 Skill 的用途，选一个主要识别符号。不要沿用历史上已被否定的深色或复杂方案。
2. 新方案或批量重绘先用代表图验证方向，再完成同系列；调用可用图像生成工具。已认可的图标复用，不因批量更新全部重做。示例生成尺寸可用 1024×1024，实际上传格式、大小和裁切以当前网页为准。
3. 做同尺寸预览，逐张检查 64px 识别、元素数量、系列一致性和彼此区分；检查实际文件元数据，去除不应公开的身份与本地路径。
4. 新设计尚未获确认时，展示图标或带 slug 对应关系的总览供用户认可，再上传；既有确认适用于未变化的方案，不重复请求。

## 网页上传

首次带图标发布按 [腾讯流程](tencent-workflow.md) 上传中文 Skill 包和图标。仅改已有条目图标时：

- 打开原条目“更新”，选择 **复用当前版本**，保留 Skill 文件和原身份。
- 选择自定义图标，上传已确认图片，检查预览与提交字段。网页若要求递增版本，就用下一个可用版本，中文变更说明注明“仅更新图标，Skill 文件复用当前版本”。
- 按本次已有发布授权提交；不把图标上传到表单当作正式提交或审核发布。公开页面仍显示旧版本时记录待审核，公开新版本显示预期图标后再确认生效。

内容与图标同时变更时使用新的中文包，不能选“复用当前版本”而丢失内容变化。

## 临时产物

完成并核验发布后，清理本次生成且不再需要的下载、候选图、效果图、总览和临时包。仅清理有明确归属的本次文件；用户要求保留的最终原图保留。待审核或交接仍需的文件记录位置与用途，保留最小必要回执，不删除既有或归属不明的图片。
