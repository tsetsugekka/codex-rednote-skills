# RED Skill 字段限制

每次预提交检查和提交后核对：

| 字段 | 限制 |
| --- | --- |
| 展示名 | 最多 15 字 |
| `skill_identifier` | 最多 128 字 |
| `description` | 最多 1000 字 |
| `skill_md_content` | 最多 10000 字 |

按普通字符长度计数，字母、数字、标点、汉字、假名和空格均计 1 字。展示名避免空格，曾观察到上传器截断为首词；返回 payload.name 必须与预期完全一致。

超限先缩短展示名、简介；简介保留用途、触发条件与核心流程。主说明保留必要入口、工作流和安全边界，把条件细节移入随包 Reference，不直接删掉执行规则。提交版以当前官方工具／平台拒绝信息为准。

示例：`Codex Skill GitHub发布` → `Skill发GitHub`；`Codex硬盘高频写入Bug修复` → `Codex硬盘写入修复`。更新已有条目时先保留原展示名，确需更名按用户意图处理。
