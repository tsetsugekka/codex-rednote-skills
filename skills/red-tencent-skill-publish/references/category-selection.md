# RED Skill 分类选择

按 Skill 的用户用途选择 1–2 个分类，不固定默认分类；优先复用已有条目的分类和会话决定。

| 用户用途 | 分类 |
| --- | --- |
| 代码、GitHub、部署、CLI、调试、数据库、API | 编程开发 |
| 自动化、流程整理、提醒、信息管理、个人效率 | 效率工具 |
| 写作、笔记、社交内容、文案、内容生成 | 内容创作 |
| 教程、学习计划、知识组织、语言学习 | 学习成长 |
| 会议、邮件、人事、文档、表格、业务流程 | 职场办公 |
| 股票、基金、行情、投资组合流程 | 金融理财 |
| 旅行、购物、日常规划、非医疗生活决策 | 生活决策 |
| 无明确匹配 | 其它 |

这些是已核验分类，执行时以当前官方 `tags --env prod` 返回为准。类别表示用户用途，不只表示实现技术：Python 生成小红书文案通常归内容创作。

新建时简短说明推荐理由；缺失且不确定时再询问。已有分类已获授权且本次用途未变时，不重复要求用户选择。
