# GitHub 社区语言选择

仅在同时修改 GitHub README／仓库简介时读取；RED 与腾讯的发布副本语言由 [中文发布规则](publishing-language.md) 决定。

| GitHub 目标受众 | 默认 README 和仓库简介 |
| --- | --- |
| 通用开源开发者 | 英文 |
| RED／小红书、腾讯 SkillHub、中国金融数据工作流 | 中文 |
| さくらインターネット、日本市场或日本业务流程 | 日文 |

其他语言可作为独立 `README.en.md`、`README.zh-CN.md`、`README.ja.md`；各语言的示例请求也需本地化。README 与仓库简介使用同一主语言。用户指定语言时从其要求；平台中文副本不自动改变 GitHub 源语言。
