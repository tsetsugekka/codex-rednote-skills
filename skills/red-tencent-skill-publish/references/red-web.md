# RED 网页发布 Workflow

用户明确指定网页提交，或需要在网页补齐平台字段时读取。正常内容更新优先 [CLI 流程](red-workflow.md)；用户只让网页更新工具／恢复登录时，按 [RED 环境配置](red-cli-auth.md) 操作，不转成网页提交。

1. 使用获授权的浏览器进入小红书创作服务平台的 Red Skill 管理页。核对账号、原条目和版本历史；更新保留数字 Skill ID 与 identifier。浏览器登录与 CLI 授权分别管理。
2. 首发用“上传skill”入口；已有条目从原条目“更新版本”进入。当前页面审核中可能只显示“撤回”，先确认状态与本次撤回意图，不自动撤回。
3. 按页面选择本地中文 Skill 包，根含 `SKILL.md`；AGENTS 规则先经 [包装流程](agents-wrapper.md)。只上传 [公开副本](public-package.md)，核对解析文件与字段。
4. 填写中文展示名、简介、完整介绍、递增版本、原创／转载来源和分类。遵守 [RED 字段限制](field-limits.md) 与 [分类选择](category-selection.md)；名称最长 15 字，不在这里修改 identifier 来绕过身份冲突。
5. 检查页面最终内容，按本次已获提交授权继续。涉及《Skill发布安全规范》等需接受协议时按浏览器规则单独确认；登录完成不是提交授权。
6. 提交后回到原条目和版本历史，保存实际版本、审核单与状态。审核中不能宣称公开生效；通过后回读名称、文案和内容。

当前网页字段和可用操作以当次页面为准。不从浏览器复制 cookie、token 或隐藏认证状态来绕过 CLI；网络或上传失败先核实已有版本，再按环境规则决定重试。
