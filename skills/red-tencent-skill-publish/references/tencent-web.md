# 腾讯网页发布 Workflow

首次带平台图标、用户指定网页发布或修改图标时读取。环境与身份先按 [腾讯环境配置](tencent-environment.md) 核对；完整中文内容和公开文件按 [公开打包](public-package.md) 准备。

1. 在获授权浏览器打开 skillhub.cn 的个人中心／我的 Skills，搜索已有 slug、核对所有者与公开／待审版本。更新打开原条目“更新”，首发用“发布 Skill”→普通 Skill→本地上传；用户要求原创本地包时不选 GitHub 导入。
2. 选择 ZIP 或文件夹。根必须含 `SKILL.md`，检查解析后的文件路径、数量和总大小；上传界面当前上限为 200 文件、总计 10MB，未来以表单为准。内容更新使用新包；仅改图标才选“复用当前版本”。
3. 核对 slug、中文名称、描述、版本和变更说明，以及一级分类／二级标签。中文名称可以与 RED 不同；更新保持原 slug。默认版本字段可能是 1.0.0，不能忘记填写本次版本。
4. 图标按 [图标规范](tencent-icons.md) 复用确认方案。自定义→点击上传图片打开上传弹窗→在弹窗中选择图片→检查缩放裁切→上传。2026-10-06 表单接受 jpg/png/webp、5MB 以内、64×64 至 4096×4096；检查实际页面限制。包内图片不能代替这里的图标字段。
5. 图片上传成功后检查表单预览和全部提交字段，再按已有发布授权点“提交审核”；出现需接受的新协议时按当前浏览器规则确认。文件或图标上传完成不等于提交完成。
6. 保存返回状态和版本历史，检查管理列表中的图标与版本；安全扫描／内容审核未完成时记为待审。通过后检查公开中文文案、文件与图标。

审核期间可能只开放“取消发布”／“取消更新”。先检查当前状态；若需要撤回前一轮审核，明确本次撤回与重新提交方案并取得授权，不能自动取消。提交超时先回查版本，避免重复创建。
